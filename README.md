# Calendrier Red Star FC 2026–2027

Calendrier iCalendar automatiquement actualisé des matchs du Red Star FC.

## Fonctionnement prévu

- Match à horaire connu : événement de l’heure du coup d’envoi jusqu’à H+2.
- Horaire inconnu : événement couvrant J-1 à J+1.
- Match à l’extérieur : statut « disponible ».
- Match à domicile : statut « occupé ».
- Actualisation automatique chaque mardi à 9 h.
- Publication par GitHub Pages avec une adresse stable.

## Abonnement

Le lien d’abonnement au calendrier sera ajouté après la première publication.
